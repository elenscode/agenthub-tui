# 보호 및 복구 경계

- **승인 대상**은 환경·프로젝트·CLI·자산·예상 원본·변경 후 내용입니다. 승인 뒤 Windows 사용자 DPAPI로 스냅샷을 암호화하고 저장한 파일의 복호화를 검사합니다. 공유 백업 저장소의 배타 잠금을 유지한 상태에서 복사 원본과 대상을 재검사합니다. 원본이 달라지면 새 계획이 필요합니다.
- **복합 작업**은 파일별로 적용합니다. 기존 Windows 파일은 ACL 보존 교체 API를 사용하고, 새 파일은 이미 존재하면 실패하는 방식으로 배치합니다. 작업 실패 시 적용한 항목을 역순으로 복구합니다. 다른 프로그램이 그 사이 변경한 항목은 보존하고 부분 복구로 보고합니다. Windows와 WSL 사이에서 하나의 원자적 파일 시스템 트랜잭션을 가정하지 않습니다.
- **공유와 경로**는 로컬 파일 시스템 식별 정보와 WSL의 경로 변환을 이용해 확인합니다. 쓰기나 폴더 복사 전에 경로 이탈, 심볼릭 링크, Windows 재분석 지점, 지원하지 않는 파일과 이름 충돌을 검사합니다. 하드링크나 링크 경로처럼 안전하게 교체하기 어려운 대상은 수동 검토가 필요합니다.
- **비밀정보**는 구조화 필드, 인증 관련 텍스트, 개인 키 블록을 마스킹합니다. 기본 진단 내보내기는 허용한 통계만 새로 구성합니다. 원본 구성·사전 스냅샷은 변경 처리 중 메모리에서 사용할 수 있고, 백업에는 암호화된 형태로 저장합니다. 같은 사용자 권한으로 실행 중인 외부 프로그램이나 사용자가 선택한 외부 편집기는 해당 사용자의 신뢰 경계에 속합니다.
- **MCP 서버**는 사용자 승인 후 실행할 수 있는 외부 코드입니다. 진단은 초기화, 초기화 완료 통지, 도구 목록 조회를 수행합니다. 전체 제한 시간 12초, 응답 본문 128 KiB, stderr 64 KiB, 도구 512개 및 페이지 상한을 둡니다. 서버가 반환한 임의 오류 본문과 도구 설명은 출력하지 않습니다.
- **WSL Helper**는 선택한 배포판의 일반 사용자로 실행합니다. 설치 전에 경로와 ELF 아키텍처를 확인하고, 설치 후와 요청 전 SHA-256을 대조합니다. 프로토콜 버전·요청 ID를 검사하며, stdout은 JSON 응답에 사용합니다. 호스트 연결이 닫히면 대기 중인 요청을 취소할 수 있습니다.
- **용량과 보관**은 파일당 2 MiB, 작업 대상 폴더당 8 MiB·2,048개 항목, Helper 메시지당 32 MiB로 제한합니다. 감사 로그는 로컬에서 회전하고 백업 이력에는 작업별 스냅샷을 남깁니다. Windows 사용자 프로필과 DPAPI 키를 잃으면 해당 계정으로 보호한 백업을 복호화할 수 없습니다.
